# SkillForge - Freelancer Marketplace Platform

SkillForge is a full-stack freelancer marketplace platform that connects clients with skilled professionals. The system enables users to create profiles, post projects, submit proposals, manage contracts, and collaborate efficiently in a secure environment.

## 🚀 Features

### User Management
- User registration and login
- Role-based access control
- Profile creation and management

### Project Management
- Create and post projects
- Browse available opportunities
- Manage project lifecycle

### Freelancer Workflow
- Submit project proposals
- Track proposal status
- Manage assigned projects

### Client Workflow
- Review freelancer applications
- Hire suitable candidates
- Monitor ongoing work

### Collaboration Features
- Project communication tools
- Progress tracking
- Work submission management

### Dashboard
- Personalized user dashboard
- Project statistics
- Activity monitoring
